# AdScoop → F&P research handoff

Lean pipeline when long-running Meta Ad Library winners (found via **[AdScoop](https://adscoop.app/)**) inform an F&P Studio campaign. **AdScoop is research / swipe only — not a generator.** It is an external tool and **not affiliated with Meta**. Do not vendor AdScoop IP, UI copy, or exports into this repo or into pack identity.

**Hard rule:** competitor stills and transcripts are **reference-only**. Patterns, not pixels. Never restage a saved ad frame into Generate output.

## Steps

### 1. Research in AdScoop / Meta Library

- Pull **3–5 long-running** ads (days live matters).
- Save a board; download **stills + transcript** (or captions).
- For each winner, note only: **hook**, **offer shape**, **CTA type**, **format**, **days live**.
- Keep files out of campaign pack locks — research folder / notes only.

### 2. Extract principles → Campaign DNA / Research (swipe brief)

- Distill **patterns**, not layouts or pixels (e.g. “cold open → proof → offer,” not “same crop / same type lock”).
- Write the swipe brief into **Campaign DNA / Research**.
- Explicitly list **what we will NOT copy** (frames, slogans, trade dress, distinctive packs, competitor marks).

### 3. Original DNA lock

- **Creative Director** invents an **F&P-only** pack + lines grounded in DNA — never blank packs, never competitor identity.
- **Critic** runs an **originality check** against [`../ORIGINALITY.md`](../ORIGINALITY.md) **before** Generate.
- AdScoop assets stay **reference-only**; they never become pack identity or locked refs for Generate.

### 4. Produce via F&P Generate

- One lean render using [`../high-end-photoreal-ads/SKILL.md`](../high-end-photoreal-ads/SKILL.md) + the configured provider (F&P Generate — not AdScoop).
- **Critic** scores → user **keep / kill**.
- Reminder: AdScoop stills/transcripts are **never** pack identity or Generate locked refs.

### 5. Loop

- On **kill**: **one Critic-fail fix per credit**, then re-score.
- Do not burn credits restaging the swipe board.

## Explicit boundaries

| Do | Do not |
| --- | --- |
| Use AdScoop for discovery + swipe notes | Treat AdScoop as an image/video generator |
| Patterns → DNA → original packs | Copy pixels, slogans, or trade dress |
| Credit AdScoop as external tool | Vendor their IP / UI into this tree |
| Critic originality before Generate | Skip Critic to “match the winner” |
